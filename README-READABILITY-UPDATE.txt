OLUCHI KONCEPT — READABILITY UPDATE

This package contains the complete OLUCHI KONCEPT website with an accessibility-focused typography update.

What changed:
- Increased body copy, service descriptions, lists, labels, captions and navigation text sizes.
- Improved text contrast on the dark background.
- Increased form input and button sizes for comfortable phone use.
- Improved small-screen typography and navigation tap targets.
- Preserved the existing black, navy and gold visual identity, imagery, motion effects, Supabase integration and site functionality.

Netlify deployment:
1. Extract this ZIP.
2. In Netlify, open the existing OLUCHI KONCEPT site.
3. Open the Deploys area and use the manual deploy / deploy folder option (or drag the extracted folder contents into the deploy drop zone).
4. Upload the extracted site folder contents, with index.html at the root.
5. After deployment, refresh the site on Android. If an old stylesheet remains cached, refresh again or clear the browser cache for the site.

This is a frontend-only update. It does not change the Supabase database, authentication, policies, tables, storage or advertisement records.
